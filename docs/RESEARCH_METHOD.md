# Build verification and benchmarking

Each preset should identify exact game version (prefer SHA/hash), race compatibility, class, spec, talent point order, spell/passive priorities, gear and alternatives, zone, difficulty, source URL/date, intended objective, proof status, and test sample size.

Starter presets are **editorial hypotheses only**, not best-in-slot recommendations.

Use paired reproducible gameplay comparisons: same patch, zone, difficulty and run duration; compare kills/time, effective DPS, boss DPS, healing, damage taken, run completion, and frame-time quantiles. Preserve separate tests for no-movement idle builds and active builds. Record seed when available. Exclude unequal runs. Report confidence and regressions.

Possible independent tools: AZSSpellMeter for per-spell source attribution, and opt-in separately installed UI addons. Do not scrape private Discord or copy protected third-party code.
