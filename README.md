# azeroth-survivors-enhanced
 
## Actual in-game Control Center (preview)

The self-authored `AZSEControlCenter` addon adds a visible, movable AZSE button and `/azcc` (`/azmenu`) **inside** the original Windows game. Seven tabs: Dashboard, Interface, Level-ups, Builds, Mods, Cheats, Settings. It genuinely toggles stock HUD parts, manages stored level-ups, shows run statistics, and offers addon on/off for next restart only if the relevant old-WoW APIs are exposed. The Cheats tab explicitly marks God Mode/gold/XP/unlocks unavailable; there is no fake effect or native hook. Standalone install instructions: `docs/INGAME_CONTROL_CENTER.md`. Exact Windows 0.137 game runtime smoke testing is still pending.
